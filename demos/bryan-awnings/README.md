# Bryan Awnings — Demo Site

One-page demo website for **Bryan Awnings** (Franklin, TX), a family-owned
aluminum patio cover and awning business. Built as part of round 2, batch 2
of the trades outreach campaign (owner-authorized batch build — see the
Lead's brief for this batch).

Lightweight static site: plain HTML + CSS, no frameworks, no build step —
deployable as-is to any static host.

## Why this business

A genuinely 50-year-old family business (1975&ndash;present) with no website
and an almost-empty online footprint &mdash; the single strongest, most
verifiable fact available (five decades in the same trade) carries this
site rather than review volume, which this business doesn't have.

## Brand system (derived, not extracted — disclosed honestly)

| Element | Choice | Rationale |
|---|---|---|
| Primary dark | Deep navy `#1c2b3f` | A vintage, Americana sign-painting-era color, evoking the mid-1970s founding rather than a modern "outdoor living" template |
| Accent | Brick red `#a13a2e` | Paired with navy for a classic, aged, trustworthy combination distinct from every other demo's palette in the gallery |
| Neutral | Aged cream `#f2e8d5` / tan `#d9c49a` | Evokes awning canvas and aluminum, avoids the browns/oranges already used heavily elsewhere in the gallery |
| Display font | Abril Fatface | Bold vintage serif display, evoking a hand-painted 1970s storefront sign |
| Body font | Libre Baskerville | Classic serif body text, reinforcing the heritage feel |
| Accent font | Special Elite | A typewriter-style face used for badges/labels ("Est. 1975," stat labels) &mdash; an intentional nod to an old paper record/receipt, fitting a business whose strongest asset is its age |
| Signature motif | Alternating navy/brick vertical-stripe divider (`repeating-linear-gradient`) | An original CSS pattern echoing awning-fabric striping in general (not any specific real awning's pattern or logo) |

No fonts, colors, or motifs here are shared with any other demo currently in
`demos/` (checked against the ~47-site catalog before finalizing).
